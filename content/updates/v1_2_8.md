## Highlights

- Configure automatic or manual HTTP/HTTPS proxies for app services and Dataverse requests.
- Monitor MCP server status and inspect invocation details with improved status feedback.
- Search across categories using global search tabs and filtering.
- Select connections through an improved workflow, including connection-aware MCP requests.
- Run Dataverse batch requests with response headers and transactional changesets.
- Use declared .NET worker processes with managed startup and communication.

## Fixes

- Fixed Dataverse HTTP proxy handling and improved proxy failure diagnostics.
- Handled command shims during tool package installation on Windows.
- Added color SVG icon display and icon loading for locally installed tools.
- Improved .NET worker process handling on Windows.
- Closed notification history after clearing it.
- Fixed button mnemonics in tool message boxes.
- Applied dedicated response size limits to Dataverse metadata and individual Web API responses.

## Developer & Build

- Added MCP server status management, invocation status details, and positional connection input support.
- Added batch response headers and transactional changesets to `dataverseAPI`.
- Added Node.js HTTP/HTTPS proxy configuration with automatic detection and manual override.
- Reduced unnecessary worker process checks during request handling.
- Added Nix source builds, a development shell, and desktop integration with the `pptb://` handler.

## Install

- Windows x64: `Power-Platform-ToolBox-1.2.8-x64-win.exe` or `Power-Platform-ToolBox-1.2.8-x64-win.msi`
- Windows ARM64: `Power-Platform-ToolBox-1.2.8-arm64-win.exe` or `Power-Platform-ToolBox-1.2.8-arm64-win.msi`
- macOS x64: `Power-Platform-ToolBox-1.2.8-x64-mac.dmg`
- macOS ARM64: `Power-Platform-ToolBox-1.2.8-arm64-mac.dmg`
- Linux: `Power-Platform-ToolBox-1.2.8-x86_64-linux.AppImage`

## Notes

- No manual migration needed; existing tool connection declarations and primary/secondary APIs remain supported.
- .NET worker use is opt-in and requires user consent for native execution.
